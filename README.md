# MerAlarm

메루카리(jp.mercari.com)에서 원하는 키워드의 **신착 상품과 가격 인하를 감시해
텔레그램이나 디스코드로 알려주는 프로그램**입니다.

Python 설치나 코드 수정 없이 실행 파일 하나로 동작하고, 설정은 전부 봇에게 명령을
보내서 합니다. 설정 파일을 열 일이 없습니다.

### ⬇️ [최신 버전 내려받기](https://github.com/SONAMYSonic/MerAlarm_forTelegram/releases/latest)

---

## 바로 시작하기

1. 위 링크에서 **MerAlarm-vX.X.X.zip** 을 받습니다
2. 압축을 풉니다 — **바탕화면이나 문서 폴더처럼 쓰기가 되는 곳**에
3. `MerAlarm.exe` 를 두 번 누릅니다

창이 뜨면 안내에 따라 텔레그램 봇을 만들고 토큰을 붙여넣으면 끝입니다. **3분이면 됩니다.**

봇 만드는 법을 단계별로 알려주고, 붙여넣은 토큰이 진짜 되는지 그 자리에서 확인한 뒤,
봇에게 메시지를 보내면 대화 상대를 자동으로 찾아 테스트 알림까지 보냅니다. 마지막에
감시할 키워드를 하나 물어봅니다.

> ### ⚠️ "Windows의 PC 보호" 창이 뜨면
>
> 개발자 서명이 없는 프로그램이라 나오는 경고입니다.
> **추가 정보** → **실행** 을 누르면 됩니다.
>
> 백신이 경고할 수도 있습니다. PyInstaller 로 만든 프로그램에서 흔한 오탐입니다.
> 미덥지 않으시면 [소스에서 직접 빌드](#소스에서-직접-쓰기)하실 수 있습니다.

### 필요한 것

- Windows 10 또는 11
- **텔레그램 계정 또는 디스코드 계정** — 둘 중 하나만 있으면 됩니다
- 메루카리 계정은 **필요 없습니다** — 로그인 없이 검색만 합니다

둘 다 무료이고, 봇을 만드는 데 돈이 들지 않습니다.

## 쓰는 법 — 봇에게 말을 걸어서

봇에게 `/help` 를 보내보세요. 설정 파일을 직접 열 일이 없습니다.
**텔레그램이든 디스코드든 명령은 똑같습니다.**

| 명령 | 하는 일 |
|---|---|
| `/add 키워드` | 감시 시작 |
| `/add 키워드 -제외어` | 특정 단어가 든 상품은 빼고 |
| `/list` | 지금 보고 있는 목록 |
| `/del 번호` | 빼기 |
| `/config` | 현재 설정 전부 |
| `/set 항목 값` | 설정 바꾸기 |
| `/pause` · `/resume` | 잠시 멈춤 / 다시 시작 |
| `/status` | 잘 돌고 있는지 |

### 제외어 붙이기

제목에 그 말이 들어가면 알리지 않습니다.

```
/add 樋口円香 -セット -まとめ
/add 樋口円香 -セット,まとめ
/add ガンプラ MG -ジャンク          키워드에 공백이 있어도 됩니다
```

**제외어에는 모두 `-` 를 붙여야 합니다.** 하나라도 빠지면 그것이 키워드의 일부인지
제외어인지 알 수 없으므로, 추측하지 않고 거절한 뒤 무엇이 잘못됐는지 알려줍니다.
잘못된 입력은 설정 파일에 아무것도 쓰지 않습니다.

### 설정 바꾸기

```
/set interval 60          감시 주기(초)
/set age 7                출품 7일 이내만
/set bump 0               끌어올린 상품은 신규로 안 침
/set krw off              원화 환산 끄기
/set 2 price_max 50000    2번 키워드만 가격 상한
/set 2 price_max off      해제
```

`/set` 만 치면 바꿀 수 있는 항목이 나옵니다.

| 범위 | 항목 |
|---|---|
| 전체 | `interval` `gap` `age` `bump` `batch` `krw` `drop` `night` `heartbeat` `keep` |
| 키워드별 | `interval` `price_min` `price_max` `age` `bump` |

#### `age` 와 `bump` 의 차이

메루카리는 판매자가 상품을 **끌어올리면**(가격을 만지거나 설명을 고치면) 검색 위로
다시 떠오릅니다. 그러면 우리 눈에는 처음 보는 물건이라 새 매물처럼 보입니다.

두 설정이 서로 다른 질문을 합니다.

| | 묻는 것 |
|---|---|
| `age` | 출품한 지 **며칠 됐나** |
| `bump` | 출품하고 **며칠 뒤에 갱신됐나** |

```
5일 전에 올려두고 그대로       →  age 5 · bump 0   ← 늦게 발견한 새 매물
5일 전에 올리고 오늘 끌어올림  →  age 5 · bump 5   ← 이미 있던 물건
```

`age` 만으로는 이 둘을 구분할 수 없습니다. 그래서 **끌어올린 것을 걸러내려면
`bump`** 를 씁니다.

```
/set bump 0     끌어올린 것은 신규로 안 침 (권장)
/set bump 3     3일 안에 갱신된 것까지는 새 매물로 인정
/set bump off   제한 없음
```

`bump 0` 을 켜면 `age` 를 느슨하게 잡아도 소음이 늘지 않습니다. **"오래된 물건이라도
새로 올라온 거면 알림"** 이 되죠.

```
/set keep 400
/set age 365
```

> **둘 다 신규 알림에만 적용됩니다.** 걸러진 상품도 가격은 계속 기록해 두었다가,
> 값을 내리면 그때 📉 로 알려드립니다.

키워드별 항목에 `off` 를 주면 그 지정을 지웁니다. 주기는 전체값을 따르고, 가격·경과일은
제한이 없어집니다.

> **잘못된 값으로 설정이 깨지지 않습니다.** 파일을 고친 뒤 실제로 다시 읽어보고,
> 실패하면 원래대로 되돌린 다음 무엇이 문제인지 알려줍니다. 명령 한 번으로 다음
> 실행 때 프로그램이 안 켜지는 일은 없습니다.

`/add` `/del` `/set` 은 **재시작 없이 즉시 반영**됩니다.

## 알아두면 좋은 것

**처음 켠 직후 한 번은 알림이 오지 않습니다.** 지금 올라와 있는 상품을 조용히 기억해
두고, 그다음부터 새로 올라오는 것만 알려드립니다. 키워드를 새로 추가할 때도
마찬가지라 알림이 쏟아지지 않습니다.

**끄려면** 창을 닫거나, 작업 표시줄 오른쪽 아래 종 모양 아이콘을 우클릭해 종료를
누릅니다. 아이콘이 안 보이면 `^` 를 눌러 숨겨진 아이콘을 펼치세요. 초록이면 감시 중,
주황이면 일시정지입니다.

**컴퓨터를 켤 때마다 자동으로** 띄우려면 `MerAlarm.exe` 바로가기를 만들어
`Win+R` → `shell:startup` 폴더에 넣으세요.

**두 번 실행되지 않습니다.** 창이 안 보인다고 다시 눌러도 "이미 실행 중"이라고
알려주고 끝납니다.

**감시 주기를 무리하게 줄여도 얻는 게 없습니다.** 한 번에 120건씩 확인하므로
30~60초면 놓치지 않습니다. 짧게 잡으면 차단 위험만 커집니다.

### 만들어지는 파일

| | |
|---|---|
| `config.yaml` | 설정 (봇 명령으로 바꾸는 게 더 편합니다) |
| `.env` | 봇 토큰. **남에게 보내지 마세요** |
| `data\` | 본 상품과 가격 기록 |
| `logs\` | 실행 기록. 문제가 생기면 여기를 보세요 |

## 무엇을 해주나

- **신착 알림** — 썸네일, 가격(원화 환산), 상품 상태, 배송비 부담자, 바로가기 링크
- **가격 인하 알림** — 한 번 알려드린 상품이 싸지면 얼마나 내렸는지 함께
- **필터** — 가격 상하한, 제외 단어, 상품 상태, 배송비 부담자, 출품 경과일
- **중복 제거** — 한 상품이 키워드 여러 개에 걸려도 알림은 한 번만
- **묶음 요약** — 한꺼번에 많이 올라오면 하나로 묶어서
- **스스로 관리** — 차단이 감지되면 알아서 느려지고, 회복되면 되돌아옵니다
- **생존 보고** — 매일 아침, 잘 돌고 있다고 알려줍니다
- **채널 선택** — 텔레그램, 디스코드, 또는 둘 다. 어느 쪽에서든 같은 명령을 씁니다

## 디스코드로 받기

`설정 다시하기.bat` 을 두 번 누르면 두 가지 중에 고르라고 물어봅니다.

| | 할 일 | 되는 것 | 걸리는 시간 |
|---|---|---|---|
| **웹훅** | URL 하나 붙여넣기 | 알림만 | 1분 |
| **봇** | 애플리케이션 만들고 초대 | 알림 **＋ 명령어** | 3~5분 |

**디스코드는 무료입니다.** 봇을 만들어도, 24시간 켜 두어도 돈이 들지 않습니다.
Nitro 나 서버 부스트는 봇과 아무 상관이 없습니다.

### 웹훅으로 하려면

알림 받을 채널의 **톱니(채널 편집) → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사**.
`설정 다시하기.bat` 에서 **2번**을 고르고 붙여넣습니다.

### 봇으로 하려면

1. [Discord Developer Portal](https://discord.com/developers/applications) 에서
   **New Application** → 이름을 짓고 만듭니다
2. 왼쪽 **Bot** → **Reset Token** → Yes → 나온 값을 복사합니다
   (토큰은 그때 한 번만 보입니다. 놓치면 다시 Reset 하세요)
3. `설정 다시하기.bat` 에서 **3번**을 고르고 붙여넣습니다
4. 화면에 뜨는 초대 주소를 브라우저에 붙여넣고 내 서버를 고릅니다
5. 알림 받을 채널을 고르면 끝입니다

> ⚠️ **봇 토큰은 비밀번호와 같습니다.** 남에게 보내지 마세요. 공개 저장소에 올리면
> 디스코드가 감지해 토큰을 무효화합니다.

명령은 **서버를 만든 사람만** 쓸 수 있습니다. 다른 사람이 쳐도 "주인만 조작할 수
있습니다" 가 뜨고 설정은 바뀌지 않습니다. 설정할 때 다른 사람으로 바꿀 수 있습니다.

봇은 **채팅 내용을 읽지 않습니다.** 슬래시 명령만 받으므로 "메시지 내용 읽기"
특권 권한이 필요 없고, 실제로 켜지도 않습니다.

> 웹훅과 봇을 둘 다 넣어도 **알림이 두 번 오지는 않습니다.** 봇이 있으면 웹훅은
> 쓰지 않습니다.

## 동작 방식에서 알아둘 것

**메루카리 검색의 정렬 순서는 신뢰할 수 없습니다.** 최초 출품 시각이 아니라 최근 갱신
시각 기준이라, 3년 전 상품도 가격을 한 번 고치면 상위로 올라옵니다. 실제로 상위
120건 중 15%가 출품 3개월이 지난 것이고 가장 오래된 것은 680일 전이었습니다.

그래서 **"처음 본 상품"과 "새로 나온 상품"을 구분합니다.**

- 출품한 지 오래된 상품은 **신규로 알리지 않습니다** (`/set age`, 기본 30일)
- **끌어올리기만 한 상품**도 신규로 알리지 않습니다 (`/set bump`, 기본 0일)
- 대신 **가격은 조용히 기록해 둡니다**
- 나중에 **값을 내리면 그때 알립니다** — 출품일과 무관하게

알림 머리말로 구분됩니다. 당일 출품은 `🆕`, 그보다 오래된 것은 `🔁 · N일 전 출품`.

**메루카리 Shops 상품**(전체의 5% 정도)은 사업자가 파는 것이라 링크 형태가 다르고
배송비 정보가 없습니다. 그래서 배송비 조건을 걸면 Shops 상품이 전부 빠집니다.
알림에는 `🏪 Shops` 표시가 붙습니다.

**한 상품이 여러 키워드에 걸려도 알림은 한 번만 갑니다.** 같은 작품의 캐릭터 이름을
여러 개 감시하면 흔히 생기는 일입니다. 이걸 제외 키워드로 해결하려 하면 안 됩니다 —
서로의 이름을 각자의 제외어에 넣으면 둘이 함께 나온 상품은 양쪽에서 걸러져 **아예
알림이 오지 않습니다.**

**차단이 감지되면 스스로 느려집니다.** 429나 403이 오면 주기를 2배씩(최대 15분까지)
늘리고, 연속 성공이 쌓이면 되돌립니다. 연속 실패가 3회를 넘으면 텔레그램으로 알리고,
복구되면 복구됐다고 다시 알립니다.

## 문제가 생기면

`logs\meralarm.log` 를 열어보세요. 해결이 안 되면
[이슈](https://github.com/SONAMYSonic/MerAlarm_forTelegram/issues)로 남겨주세요.
`/status` 결과와 로그 마지막 부분을 함께 적어주시면 도움이 됩니다.

| 증상 | 해결 |
|---|---|
| "이 폴더에 파일을 만들 수 없습니다" | 압축을 풀고 실행했는지, 바탕화면 같은 곳에 두었는지 확인 |
| "이미 실행 중입니다" | 트레이 아이콘을 확인하세요. 이미 돌고 있습니다 |
| 알림이 안 옴 | `/status` 로 살아있는지 확인. 첫 회차는 원래 조용합니다 |
| 원하는 상품이 안 옴 | `/config` 로 필터 확인. 출품이 오래됐으면 `/set age`, 끌어올린 것이면 `/set bump` 조정 |
| 안 원하는 상품이 옴 | 끌어올린 것이면 `/set bump 0`, 특정 단어면 `/del` 후 `/add 키워드 -단어` |

# 개발자용

여기부터는 소스를 직접 다루실 분을 위한 내용입니다.

## 소스에서 직접 쓰기

```bash
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m meralarm --setup
```

설정이 없는 채로 그냥 실행해도 마법사가 뜹니다. `--setup` 은 나중에 다시 설정할 때 씁니다.

```bash
.venv\Scripts\python.exe -m meralarm
```

> **화면이 없는 환경(systemd, `pythonw`)에서는 마법사가 뜨지 않습니다.** 입력을
> 기다리다 멈추면 서비스가 죽은 것처럼 보이기 때문입니다. 대신 무엇이 빠졌는지와
> 어떻게 해결하는지를 알려주고 끝납니다.

## 실행 파일 만들기

```bash
powershell -ExecutionPolicy Bypass -File scripts\build_exe.ps1
```

`dist\MerAlarm-vX.X.X.zip` 이 만들어집니다. 버전은 `meralarm/__init__.py` 의
`__version__` 에서 가져옵니다.

## 리눅스 서버에 올리기

```bash
bash scripts/setup.sh              # 준비
./.venv/bin/python scripts/check_access.py   # 이 서버에서 메루카리가 되는지 먼저 확인
bash scripts/install_service.sh    # systemd 등록
```

Oracle Cloud 무료 티어 기준 절차는 [DEPLOY.md](DEPLOY.md) 에 초보자용으로 정리했습니다.
데이터센터 IP 에서도 차단되지 않는 것을 확인했습니다.

> **두 곳에서 동시에 돌리지 마세요.** 같은 봇 토큰을 쓰면 알림이 두 번 옵니다.
>
> 텔레그램은 그나마 친절해서 한쪽 연결을 끊고 로그에 `conflict` 를 남깁니다.
> **디스코드 게이트웨이는 그렇게 알려주지 않습니다.** 두 연결이 조용히 함께 붙어
> 명령이 두 번 실행될 수 있으니, PC 와 서버를 같이 켜두지 않도록 주의하세요.
> (같은 컴퓨터에서는 파일 잠금이 막아줍니다)

## 채널 설정 (`.env`)

채널은 **하나만 있어도** 됩니다. 예전에는 텔레그램이 없으면 실행을 거절했지만,
지금은 하나도 없을 때만 거절합니다.

```
# 텔레그램
TELEGRAM_BOT_TOKEN=123456789:AA...
TELEGRAM_CHAT_ID=987654321

# 디스코드 — 웹훅은 알림만, 봇은 알림 + 명령어
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
DISCORD_BOT_TOKEN=MTIz...
DISCORD_CHANNEL_ID=1234567890
DISCORD_OWNER_ID=9876543210
```

알림은 임베드로 보내서 썸네일과 가격·상태·배송비가 칸으로 나뉘고, 종류에 따라
왼쪽 띠 색이 달라집니다(신규 초록 · 재등장 파랑 · 인하 주황).

**웹훅은 보내기 전용이라 명령어를 받을 수 없습니다.** 봇은 게이트웨이에 상시 접속해
슬래시 명령을 받습니다. 나가는 연결이라 포트를 열 필요가 없고, 공유기 안이든
클라우드든 똑같이 됩니다.

```
DISCORD_BOT_TOKEN 있음  →  봇으로 보내고 웹훅은 무시 (알림 중복 방지)
없음                    →  DISCORD_WEBHOOK_URL 이 있으면 웹훅으로
```

명령 응답은 한 벌만 쓰고 채널마다 다르게 그립니다. 텔레그램 HTML 을 기준 표현으로
두고 `notifiers/markup.py` 가 디스코드 마크다운으로 바꿉니다. 문구를 두 벌 두면
한쪽만 고치는 일이 생깁니다.

> 두 채널을 함께 쓸 때 **하나라도 전송에 성공하면 본 것으로 기록합니다** — 전부
> 성공해야 기록하면 한쪽이 잠깐 죽었을 때 같은 알림이 계속 다시 갑니다.

## 설정 파일

`config.yaml` 을 직접 고쳐도 됩니다. 고친 뒤에는 재시작해야 반영됩니다.

```yaml
keywords:
  - ガンプラ MG                 # 간단형: 조건 없이 전부

  - name: 芹沢あさひ            # 상세형
    query: 芹沢あさひ
    interval_sec: 30           # 이 키워드만 더 자주
    price_min: 1000
    price_max: 50000
    exclude: [セット, まとめ]   # 제목에 있으면 제외
    conditions: [1, 2]         # 새상품·미사용 / 거의 새것만
    shipping_payers: [2]       # 판매자가 배송비 부담하는 것만
    max_age_days: 7            # 이 키워드만 다르게
    max_bump_days: 0           # 끌어올린 것은 신규로 안 침
```

| 항목 | 값 |
|---|---|
| `conditions` | 1 새상품·미사용 · 2 거의 새것 · 3 눈에 띄는 상처 없음 · 4 약간 상처·오염 · 5 상처·오염 · 6 상태 나쁨 |
| `shipping_payers` | 1 구매자 부담 · 2 판매자 부담 · 3 미정 |

비워두면 그 조건으로는 거르지 않습니다. 전역 설정은 `config.example.yaml` 의 주석을
참고하세요. `store.keep_days` 는 반드시 `notify.max_age_days` 보다 커야 하며,
그렇지 않으면 실행할 때 거절합니다.

## 구조

```
meralarm/
├─ __main__.py      진입점, 조립
├─ scheduler.py     폴링 엔진 (스태거링·백오프·신규/인하 판정)
├─ config.py        설정 로드와 검증
├─ config_store.py  봇이 config.yaml 을 고쳐 쓸 때 주석 보존
├─ commands.py      명령 해석·실행(채널 무관) + 텔레그램 롱 폴링
├─ setup_wizard.py  첫 실행 설정 안내
├─ models.py        Item 표현, URL 조립
├─ filters.py       나이·가격·제외어·상태·배송비 필터
├─ store.py         SQLite (중복 제거 · 가격 이력 · 알림 원장)
├─ ratelimit.py     전역 요청 간격
├─ fx.py            엔화→원화 환율
├─ control.py       일시정지·종료 신호
├─ tray.py          작업 표시줄 아이콘
├─ single_instance.py  중복 실행 차단
├─ alerts.py        채널에 묶이지 않은 알림 표현
├─ sources/         수집기 (교체 가능)
│  └─ mercapi_source.py
└─ notifiers/       알림 채널 (교체·병행 가능)
   ├─ telegram.py        알림 + 명령 응답
   ├─ discord_webhook.py 웹훅 (보내기 전용)
   ├─ discord_bot.py     봇 (게이트웨이 · 슬래시 명령)
   ├─ discord_embed.py   임베드 만들기 (웹훅·봇 공용)
   ├─ markup.py          텔레그램 HTML → 디스코드 마크다운
   └─ queue.py           전송 큐와 채널 팬아웃
```

명령을 하나 늘리려면 `commands.py` 의 `CommandCore` 만 고치면 두 채널에 동시에
생깁니다. 채널별로 다른 것은 **받아오는 방법과 그리는 방법**뿐입니다.

수집은 셀레니움이 아니라 **메루카리 내부 API 를 직접 호출**합니다
([mercapi](https://github.com/take-kun/mercapi) 가 DPoP 서명을 처리). 요청 하나가
0.1초로 끝나기 때문에 30초 주기로 키워드 여럿을 돌릴 수 있습니다.
